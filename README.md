# Valley Agriculture

Website for Valley Agricultural Tractors & Machinery Trading W.L.L. (Bahrain), in English and Arabic.

| Path | What |
|---|---|
| [`web/`](web/) | The website (Next.js 15, Tailwind CSS v4, next-intl). See [`web/README.md`](web/README.md) to run it. |
| [`website-brief.md`](website-brief.md) | Purpose, design system, sitemap and page sections |
| [`implementation-plan.md`](implementation-plan.md) | Build phases and checkpoints |
| [`content/copy-en-ar.md`](content/copy-en-ar.md) | All site copy in English and Arabic |
| [`brand/logo/`](brand/logo/) | Logo files (original PNG and SVG versions) |

## Quick start

```bash
cd web
npm install
npm run dev
```
